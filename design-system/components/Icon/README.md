# Icon

Les sept glyphes de la maquette, dessinés en `currentColor`.

- **Fournir** : `name` (`play`, `pause`, `skip-forward`, `check`, `chevron-right`, `chevron-up`, `chevron-down`) et `size` (hauteur en px) si besoin.
- Prennent la couleur du texte parent : `on-accent` dans un bouton plein, `glyph-tertiary` pour un chevron de ligne, `glyph-secondary` pour le réordonnancement.
- Sur iOS, utiliser les SF Symbols équivalents (voir le README) plutôt que ces SVG.
