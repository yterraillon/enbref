# IconButton

Bouton rond de 44 px (`tap-target`) pour une action sans libellé visible.

- **Fournir** : `label` (nom accessible, obligatoire), `icon` ou `children` (« Aa », « 1,25× »), `onClick`.
- `surface` (défaut) : disque `surface` + `shadow-raised`, posé sur la barre de titre (« Aa »).
- `filled` : disque `accent`, icône `on-accent` — lecture / pause dans le mini-lecteur.
- `ghost` : sans fond, pour les actions secondaires du mini-lecteur (suivant, vitesse).
- Jamais plus de trois boutons ronds côte à côte.
