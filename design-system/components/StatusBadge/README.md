# StatusBadge

Ajout pour l'admin web : étiquette de statut d'un récap ou d'une brève.

- **Fournir** : `tone` (`success`, `warning`, `danger`, `neutral`) et un libellé court qui suffit seul (« Publié », « Brouillon », « Échec de génération »).
- Pilule `fill-tertiary`, texte et point dans la couleur du ton, `footnote` 600.
- Le mot porte le sens : la couleur ne fait que le renforcer (lisible par les daltoniens).
- Absent de l'app iOS.
